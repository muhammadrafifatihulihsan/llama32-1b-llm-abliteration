# Credits

The implementation draws on FailSpy's `ortho_cookbook.ipynb`, Maxime Labonne's abliteration material, and TransformerLens for working with model activations.

Tools used in the project include PyTorch, Hugging Face Transformers, safetensors, llama.cpp, and Ollama. The default model is Llama-3.2-1B-Instruct. Model weights and third-party source code are not bundled here.

The original data loader referred to AdvBench and Alpaca. That does not establish the origin of the local CSV files; see [data notes](../data/README.md).

Third-party code, models, and datasets retain their own licenses and terms. This repository does not currently include a separate software license.
